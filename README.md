#  Sanrio World

Site temático dedicado aos personagens da Sanrio, desenvolvido como Avaliação Final (AF) da disciplina de Desenvolvimento Web.

---

##  Sobre o Projeto

O **Sanrio World** é um site multi-páginas com tema fofo inspirado no universo Sanrio (Hello Kitty, Kuromi, Cinnamoroll e outros). O projeto aplica conceitos de HTML5, CSS3, Bootstrap 5 e JavaScript puro.

**Disciplina:** Linguagens de Programação  
**Instituição:** UNIFACENS  
**Ano:** 2026

##  Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| Home | `index.html` | Carrossel, apresentação e destaques dos personagens |
| Galeria | `galeria.html` | Cards com todos os personagens e suas descrições |
| Contato | `contato.html` | Formulário de contato, informações e mapa |

---

##  Tecnologias Utilizadas

- **HTML5** — estrutura semântica das páginas
- **CSS3** — estilização personalizada com variáveis CSS
- **Bootstrap 5.3.3** — grid responsivo, navbar, carrossel e componentes
- **JavaScript** — interações: validação de formulário, botão "voltar ao topo" e efeito nos cards

##  Funcionalidades

- Navbar fixa com menu responsivo (hambúrguer no mobile)
- Carrossel automático na página Home
- Cards com efeito hover (elevação e borda rosa)
- Formulário de contato com validação via JavaScript
- Botão flutuante "Voltar ao Topo" (aparece após rolar 300px)
- Mapa incorporado via Google Maps iframe
- Layout totalmente responsivo

##  Como Executar

Não requer instalação. Basta abrir o arquivo `index.html` no navegador:

```bash

git clone https://github.com/seu-usuario/sanrio-world.git


cd sanrio-world

```

> **Dica:** Use a extensão **Live Server** do VS Code para melhor experiência de desenvolvimento.
